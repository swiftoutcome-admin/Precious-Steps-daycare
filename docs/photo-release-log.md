# Photo release log

No photograph showing an identifiable child may be published on this website
without a signed publicity release on file at the centre.

**Process before any image goes live:**

1. Client confirms, in writing (email is fine), that a signed release is on file
   for every child visible in the image.
2. That confirmation is recorded in the table below with the date and the file
   name as it appears in `src/assets/img/`.
3. Only then does the image get committed.

Keep the written confirmations. Do not rely on a verbal yes.

| Image file | Children visible | Release confirmed by | Date confirmed | Published |

| | | | | |

## Removal requests

If a parent asks for their child's image to be removed, remove it from the repo
and redeploy the same day, then record it here.
